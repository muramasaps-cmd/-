# 🎰 スロット店舗 粗利・売上分析システム (Streamlit版)

スロレポHTMLデータを取り込み、ホールの粗利推移・売上・出玉率（機械割）・特日/曜日/末尾別傾向を可視化・分析できるPython / Streamlitアプリケーションです。

---

## 🚀 クイックスタート（ローカルPCでの実行方法）

### 1. Python環境の準備
Python 3.9 以上がインストールされていることを確認します。

### 2. 依存パッケージのインストール
ターミナルまたはコマンドプロンプトで本リポジトリのディレクトリに移動し、以下を実行します：

```bash
pip install -r requirements.txt
```

または直接指定してインストール：
```bash
pip install streamlit pandas plotly beautifulsoup4
```

### 3. Streamlitアプリの起動
以下のコマンドを実行すると、ブラウザが自動起動しアプリ（`http://localhost:8501`）が表示されます：

```bash
streamlit run streamlit_app.py
```

## 🌐 Streamlit Community Cloudへの無料デプロイ手順

GitHubアカウントがあれば、世界中からアクセスできるWebアプリとして無料公開できます。

1. 本リポジトリ（`streamlit_app.py`, `requirements.txt` を含む）を GitHub にプッシュします。
2. [share.streamlit.io](https://share.streamlit.io/) にアクセスし、GitHubアカウントでログインします。
3. **「New app」** をクリックし、リポジトリとブランチを選択します。
4. Main file path に `streamlit_app.py` を指定して **「Deploy」** をクリックします。
5. 数分でクラウド上にWebアプリが立ち上がります。

## 💡 主要機能

1. **多彩なデータ取り込み**:
   - プリセット（プラザ515）ですぐにお試し可能
   - スロレポHTMLファイルのドラッグ＆ドロップ（単一・複数一括取込）
   - HTMLソースコードのテキスト直接貼り付け
   - 独自CSVデータの取り込み
2. **2つの視点切り替え**:
   - **ホール目線**: 店舗粗利、店舗黒字／出玉還元
   - **スロッター目線**: ユーザー収支、客側勝ち／店側回収
3. **精緻な計算モデル**:
   - **Model B (推奨)**: G数（IN枚数）と現金投資比率・換金ギャップを連動させた高精度モデル
   - **Model A**: 単純差枚数換算モデル
4. **多角的な分析タブ**:
   - **月別推移 & 累積乖離ペース**: 月間目標ペースに対する回収・放出の波を可視化
   - **日別データ一覧**: フィルター・検索・並び替え
   - **曜日別分析**: 月〜日の回収／還元傾向
   - **末尾日分析**: 日付末尾 0〜9 の平均差枚・粗利ランキング
   - **特日 vs 通常日比較**: 旧イベント日の信頼度検証
   - **CSVエクスポート**: 計算済み日別データのワンクリックダウンロード
